# System Design in Kannada 🧠

**Free, structured System Design course — from absolute zero to interview-ready — explained in Kannada.**
One concept per video · simple notes · homework for every video.

> ⭐ Star this repo to follow along. Homework answers go in the **Discussions** tab.

## How this course works
- 🍽️ **One running story — Oota**, a food-delivery app. It starts on one laptop and grows to crores of users. Every video = one problem Oota hits + the concept that fixes it.
- ☕ **One analogy world — Namma Darshini.** Cooks, token counters, idli trays and branches explain every concept.
- 📝 **Homework in 4 levels:** 🧠 Think · ✏️ Draw · 🛠️ Build · 🎯 Interview.
- 🎯 **Interview Line** in every video — the one answer to remember.
